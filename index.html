❓ Frequently Asked Questions

Is this tool compatible with my computer?

This tool is designed for Windows 10 and Windows 11. If you're using an older version of Windows (like 7 or 8), it might still work, but for the best experience, we recommend using a modern Windows version.

Will this work with my code in Roblox Studio?

Absolutely! Since Roblox uses Luau, this tool understands Luau code perfectly. You can copy your code from Roblox Studio, format it with this tool, and then paste the clean code back – or use the tool directly on your project folders.

Can this tool break my code?

No, it's generally safe. The tool only changes the layout of your code (spaces, line breaks, alignment). It does not change the logic of what your code does. That said, it's a good habit to save a backup of your original code before formatting, especially if you are working on a big, important project. Most users don't have any issues.

Do I need to know programming to use this?

Not at all! If you can double-click a file and click a button, you're all set. This tool was designed to be super easy for everyone, from beginners to professionals.

Is there any cost?

No. This is a free open-source utility. It's provided for the developer community to help everyone produce cleaner code.
